# usavote

**Check publishing rights before publishing anything.** This repository is public and GitHub Pages serves `main`, so a commit that's pushed to any branch is published, merged or not, and can't be reliably taken back. Before any data, or anything built from it, goes into a commit, a pull request or an issue:

1. Read the source's terms of use in full, from the source itself, not a summary.
2. Confirm they cover this use: redrawing, simplifying and republishing results and shapes.
3. If they're silent, unclear or limiting, keep the data and everything built from it local and git-ignored, and ask the owner before publishing.

Record what was read in the state's `docs/records/<state>.md`. The rules and past decisions are in `docs/PIPELINE.md`, Parts 5 and 8.
